# Machine Learning, Deep Learning & AI — Teaching Repository

This repository contains the code, notes, examples, and datasets used in my Machine Learning, Deep Learning, and AI teaching sessions.

It is primarily maintained as a learning resource for the students I teach, so they can access the material, practice the code, and refer back to the topics covered in class.

The repository is continuously updated as new topics are taught.

## For Students

If you are a student attending my classes, you can use this repository to:

- Access class notes
- Follow the code demonstrated during sessions
- Practice concepts using the provided examples
- Access datasets used in class
- Revisit previous topics
- Use the notebooks for self-practice

The repository will be updated regularly as we progress through new topics.

## For Recruiters / Interviewers

This repository also serves as a record of the technical material and practical examples I use while teaching.
